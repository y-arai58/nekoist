# nekoist診断 判定仕様 v1

## 判定フロー

1. 36問を1〜5で回答する
2. 各回答を左右への寄与率へ変換し、12属性を0〜100に正規化する
3. 覚醒7タイプの発動条件をすべて評価する
4. 覚醒が成立した場合は、同点処理を経て1タイプを返す
5. 覚醒が成立しなかった場合だけ通常9タイプを比較し、1タイプを返す

## 回答と配点

各質問の左右に、主属性2点・副属性1点を割り当てる。

| 回答 | 1側への寄与 | 5側への寄与 |
| ---: | ---: | ---: |
| 1 | 100% | 0% |
| 2 | 75% | 25% |
| 3 | 50% | 50% |
| 4 | 25% | 75% |
| 5 | 0% | 100% |

属性ごとに `獲得点 ÷ 獲得可能な最大点 × 100` で正規化する。質問文と左右の属性割り当ては `src/domain/questions.ts` を正本とする。

## 覚醒7タイプ

回答値は、5側方向を `1=0, 2=25, 3=50, 4=75, 5=100` とする。1側方向は反転する。

| タイプ | 適合度 | 発動条件（すべて必須） |
| --- | --- | --- |
| うちの子原理主義 | `0.35A + 0.35(100-B) + 0.30LOYAL` | A≥75、B≤45、LOYAL≥75、適合度≥78、Q6/Q7が両方4以上 |
| 猫の下僕 | `0.50K + 0.20A + 0.30SERVANT` | K≥80、A≥65、SERVANT≥75、適合度≥80、専用5問中3問以上が4以上 |
| 猫界の母なる大地 | `0.45B + 0.25D + 0.20max(D,E) + 0.10A` | B≥80、max(D,E)≥72、MOTHER≥70、適合度≥80、D≥65またはE≥80 |
| 猫教司祭 | `0.50I + 0.40J + 0.10A` | I≥80、J≥78、PRIEST≥75、適合度≥82、専用5問中3問以上が4以上 |
| 猫の子ども | `0.55L + 0.30C + 0.15A` | L≥80、C≥68、CHILD≥75、適合度≥80、専用5問中3問以上が該当方向へ4〜5相当 |
| 猫博士 | `0.60G + 0.30F + 0.10D` | G≥82、F≥70、DOCTOR≥75、適合度≥80、G-D≥5 |
| 猫界の仙人 | `0.55E + 0.30F + 0.15C` | E≥82、F≥70、SAGE≥75、適合度≥80、E-H≥10 |

専用質問は以下。

- LOYAL: Q6, Q7（5側）
- SERVANT: Q1, Q2, Q21, Q22, Q34（5側）
- MOTHER: Q5, Q9, Q10, Q33（5側）
- PRIEST: Q16, Q19, Q27, Q28, Q29（5側）
- CHILD: Q24, Q25, Q26, Q36（5側）、Q35（1側）
- DOCTOR: Q8, Q15, Q17, Q18（5側）、Q31, Q33（1側）
- SAGE: Q3, Q4, Q10, Q15, Q17（1側）

複数の覚醒が成立した場合は、適合度差3点以上なら高い方を採用する。3点未満なら、中核属性の最低値（差2点以上）、突出度、専用質問スコアの順で比較する。

## 通常9タイプ

| タイプ | 適合度 |
| --- | --- |
| 一途な猫守り | `0.35A + 0.30(100-B) + 0.25LOYAL + 0.10C` |
| 猫の親友 | `0.60C + 0.20A + 0.10L + 0.10H` |
| 猫の保護者 | `0.60D + 0.15G + 0.15A + 0.10K` |
| 全猫の母 | `0.50B + 0.30D + 0.10A + 0.10E` |
| 猫界の隣人 | `0.60E + 0.20C + 0.20F` |
| 猫観察家 | `0.65F + 0.15B + 0.15E + 0.05I` |
| 猫研究家 | `0.65G + 0.20F + 0.10D + 0.05C` |
| 猫吸い職人 | `0.70H + 0.15A + 0.10C + 0.05K` |
| 猫教信徒 | `0.65I + 0.15A + 0.10K + 0.10F` |

近似タイプの差分ボーナスは次の通り。

- E−F≥10: 猫界の隣人 +5
- F−E≥10: 猫観察家 +5
- G−D≥10: 猫研究家 +5
- D−G≥10: 猫の保護者 +5
- C−H≥10: 猫の親友 +5
- H−C≥10: 猫吸い職人 +5
- I−F≥10: 猫教信徒 +5

1位と2位の差が3点未満なら、主属性、タイプの象徴質問一致度、小数点以下を含む元の適合度の順で比較する。理論上の完全同点には、回答ベクトル由来の決定的な指紋を最終安全策として使い、ランダムにはしない。
